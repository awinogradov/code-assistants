## Release Notes

The `linear-plan` skill now stores plans using a strict template that guarantees valid Linear markdown, preventing parse errors when plans are executed via `linear-run`.

## ✨ What's New

### Strict Plan Storage for Linear Tickets

When the `linear-plan` skill stores a plan on a Linear ticket, it now uses a controlled emission template that limits output to Linear-safe markdown only. Previously, stored plans could include markdown constructs that Linear's parser doesn't support, causing issues when those plans were later picked up and run by `linear-run`. Plans stored from this release forward will always parse cleanly in Linear, making the plan → execute workflow more reliable end-to-end.
