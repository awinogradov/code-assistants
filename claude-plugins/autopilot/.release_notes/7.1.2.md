## [7.1.2](https://github.com/awinogradov/code-assistants/compare/autopilot@v7.1.1...autopilot@v7.1.2) (2026-08-27)

## Release Notes

Agents can no longer accidentally overwrite committed Graphify artifacts during autopilot runs.

## 🐛 Bug Fixes

### Graphify Restricted to Read-Only for Agents

Autopilot skills previously gave coding agents unrestricted access to all Graphify commands, which meant an agent could silently run `graphify update .` mid-task and overwrite committed graph artifacts — making diffs noisy and potentially corrupting the state other team members depend on. Agents are now limited to the read-only Graphify commands only (`query`, `path`, `explain`, `affected`, `help`). Stack rule templates have also been updated to remove any instruction that told agents to refresh the graph after code changes. Committed Graphify artifacts are treated as immutable during agent work; regenerating them remains a deliberate, human-initiated step.
