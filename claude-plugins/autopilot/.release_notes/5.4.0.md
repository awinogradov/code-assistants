## [5.4.0](https://github.com/awinogradov/code-assistants/compare/autopilot@v5.3.0...autopilot@v5.4.0) (2026-08-13)

## Release Notes

The most impactful change in this release is that `linear-run` now enforces that codebase context is always sourced through Graphify or Repomix — runs that skip source selection fail fast with a clear error instead of silently falling back to ordinary file search.

## ✨ What's New

### Smarter Graphify Query Refinement

When Graphify returns a truncated or empty graph answer during a context pass, Autopilot now automatically retries with a narrower query before giving up and falling back to file search. Previously, the first answer was treated as complete even if it was cut short. Now, the context pass ends with a bounded shortlist of relevant files, and a `graphify-trace:` line is recorded capturing query count, truncation status, shortlist size, and any reads outside the shortlist. The Context Map's Snapshot section also now carries the Graphify shortlist forward, so downstream phases (plan, run) reuse what the graph already found rather than re-querying from scratch.

### Enforced Context Source in Linear Runs

`/autopilot:linear-run` now enforces that a codebase context source — Graphify or Repomix — was actively selected and recorded during the context phase. If a run reaches the planning phase without a verified source on record, it stops immediately with a clear error. This applies to both stored-plan and fresh-plan Linear run flows. The previous behaviour allowed runs to silently re-scan the repository using ordinary file search when no source was confirmed, which could produce inconsistent or lower-quality plans without any warning.
