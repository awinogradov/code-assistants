## [10.0.0](https://github.com/awinogradov/code-assistants/compare/autopilot@v9.0.1...autopilot@v10.0.0) (2026-09-18)

## Release Notes

Skills no longer use Graphify or Repomix for context acquisition — all codebase context now comes from `Grep`/`Glob`/`Read` and `git` only.

## ⚠️ Breaking Changes

### Graphify and Repomix Context Tiers Removed

Skills no longer query a Graphify graph or attach a Repomix pack. Remove `Bash(graphify …)` and `MCP(repomix:*)` from any custom `allowed-tools` overrides, and remove `mcp__repomix__*` from any code-review action tool configurations. The following artifacts are gone from skill output:

- Plan `## Context source` section
- Context Map `**Snapshot**` field
- `context-source:`, `graphify-trace:`, `graphify-shortlist:`, and `context-fallback:` records

Follow the `9.0.1 → 10.0.0` instructions in [MIGRATING.md](https://github.com/awinogradov/code-assistants/blob/main/claude-plugins/autopilot/MIGRATING.md) before deploying.
