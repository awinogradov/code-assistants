## Release Notes

Autopilot can now cleanly complete tasks that require no code changes, avoiding the creation of empty pull requests.

## ✨ What's New

### Clean Completion for No-Change Tasks

When Autopilot determines that a task is already done — either because an external action handled it or because no code changes are actually needed — it now exits gracefully without opening a pull request. Previously, these scenarios could result in an empty or meaningless PR being created. Now the `run` skill recognises this outcome as a valid completion state and stops there, keeping your pull request queue clean and free of noise.
