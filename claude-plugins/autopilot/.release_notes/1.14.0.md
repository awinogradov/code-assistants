## [1.14.0](https://github.com/awinogradov/code-assistants/compare/autopilot@v1.13.0...autopilot@v1.14.0) (2026-07-26)

## Release Notes

A new `/autopilot:explore` skill makes it possible to map an entire repository and save a reusable context brief, then apply targeted fixes immediately without any planning, branching, or PR ceremony.

## ✨ What's New

### Explore Skill for Rapid, Branchless Fixes

The new `/autopilot:explore` skill gives you a fast path when you want to understand a codebase and make surgical changes without spinning up a full planning workflow. When invoked, it broadly maps the repository, saves a durable context brief you can reuse across sessions, and then lets you apply fixes one at a time — no plan, no branch, no PR required.

This is ideal for quick investigations, hotfixes, or exploratory work where the full review-and-PR cycle would be overkill.

### Optional Scope for Context Gathering

Context gathering now supports an optional `Scope` setting that controls how broadly the codebase is analysed when building the context brief. Existing planning flows that don't set this value are completely unaffected — this is a purely additive change.
