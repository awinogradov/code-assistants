# Component Patterns

Reference for [`ascii-schemas/SKILL.md`](../SKILL.md) — individual UI widget patterns used inside wireframes.

## UI Component Patterns

**Toggle switch:**

```
[●──] On label           [──●] Off label
```

**Checkbox:**

```
[✓] Checked item          [ ] Unchecked item
```

**Radio button:**

```
(●) Selected option       ( ) Unselected option
```

**Select/dropdown:**

```
┌──────────────────────┐
│ Selected value     ▾ │
└──────────────────────┘
```

**Progress bar:**

```
▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓░░░░░░░░░░░░░░░░
```

**Rating:**

```
●●●●○ (128 reviews)
```

**Stepper:**

```
● Account ─ ● Profile ─ ○ Plan ─ ○ Confirm
```

**Breadcrumb:**

```
Home / Shoes / Running / Air Max Pro
```

**Divider with label:**

```
── Section Title ──────────────────────
```

**Image placeholder:**

```
┌────────────────────────────────────┐
│░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░│
│░░░░░░░░░░░░Product Photo░░░░░░░░░░░│
│░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░│
└────────────────────────────────────┘
```
